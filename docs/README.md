## 3. 维护规范（新增/修改文档时遵守）

1. **编号即顺序**：新文档取下一个编号（08、09……），主题保持"一类一文档"，不新建散页。
2. **数值必须带口径**：任何指标数字须标注基线文件名 + 索引 md5；索引变更后旧读数整体作废（答案缓存按 index_md5 判废），不得混用。
3. **改动如实记录**：文档须与代码现状一致；发现历史误标（如 05 曾把图片双向量误标 S7）时，修订并留"原误标为 X，修订于 YYYY-MM-DD"注记，不得静默改写。
4. **互引用相对路径**：文档间引用写 `0X-xxx.md`（同目录）或 `../文件名`（指版本根），不使用绝对路径。
5. **合并保留溯源**：合并产生的文档，在原文章节处保留来源说明；被合并原文档删除前须通过内容保全验证（末行抽样 + 行数核算）。
